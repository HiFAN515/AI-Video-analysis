# 原始需求（设计目标）

1. 使用者给出 Bilibili 视频链接，工具自动下载音频，将音频转文本并进行 AI 解析。
2. 工具有交互界面（网页），使用者可以提供视频链接、确认后再下载解析，并可以选择解析完成后是否删除音频。
3. 音频转文本需要规范化：背景音乐抑制、降噪、说话人分离、ASR 等标准流程，而不是直接进行 ASR。
4. 解析完文本后，可以选择使用 AI 进行分析，判断内容正误、提供补充观点等。
5. 要有存储库，存储每个转文本后的内容、使用者与 AI 讨论的内容等。
6. 实现之前先在 GitHub 上搜索可使用的项目，而不是直接从头开始。

> 需求 6 的调研结论与选型见 [DESIGN.md](DESIGN.md)。
